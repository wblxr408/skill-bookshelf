# peer review

The peer panel retains Editor-in-Chief, methodology reviewer, domain reviewer, cross-disciplinary reviewer, and Devil's Advocate perspectives, with field-specific personas and criteria. Keep independent candidate findings blind when running authorized independent agents; disclose correlated/shared-model judgment when a single agent performs the perspectives. Merge duplicate defects with all supporting evidence, never suppress a valid issue merely to create non-overlapping reports.

Available modes: full, quick assessment, methodology focus, guided/Socratic, re-review verification, and calibration. Load the relevant mode section via the peer module's index and its reference protocol. Preserve individual reviewer reasoning, quality rubrics, field expertise, editorial decision categories, revision roadmap, reviewer accuracy/calibration inputs, and uncertainty. Cross-model Reviewer 2 remains an optional substrate; actual upload of a manuscript to an external provider requires user authorization. Configuration alone is not consent. Failed external dispatch falls back only with disclosure. No fixed backend, model tier, four-call generator protocol, or missing Claude-specific tool is mandatory in this Codex environment.
