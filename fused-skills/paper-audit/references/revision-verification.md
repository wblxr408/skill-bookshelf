# revision verification

Read the previous issue register/review comments and current manuscript. Map each comment to a concrete change, source location, and acceptance evidence. Mark resolved, partially resolved, unresolved, newly introduced, or not applicable with reasons. Preserve issue identifiers and severity unless new evidence justifies a change.

Use retained re-audit/re-review, issue-diff, consolidation, revision-trajectory, and editorial templates only as needed. Rebuttal audit checks whether responses answer reviewers, match actual revisions, support disputed claims, and avoid unsupported concessions. Route writing of responses or source patches to academic-paper's writing/revision module. Do not silently edit a manuscript during a review-only request or repeat unaffected whole-paper audits.
