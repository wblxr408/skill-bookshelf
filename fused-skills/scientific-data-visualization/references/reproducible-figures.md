# reproducible figures

Use `modules/reproducible/scripts/inspect_data.py` for undocumented data. Read that module's data-contract and chart-catalog; select a chart from the analytical question and data facts. Gallery search uses its gallery-routing plus query_gallery/build_gallery_index/route_from_prompt, returning compact candidates instead of loading screenshots/catalogues wholesale.

For inference read ai-recommendation-protocol and run recommend_statistics; preserve eligible/conditional/inapplicable distinctions, experimental unit/independence/pairing/outlier/missingness review, and confirmed-method/effect-size/power constraints when they apply. Descriptive charts do not require an inferential method interview. Do not load formula context without a requested explanation or custom computation.

Use named themes and versioned JSON/YAML specs, record style overrides, render with render_figure.py, and inspect render-report.json and the preview. A statistics annotation requires the verified result and confirmed method. For journal-specific or custom layout details add the publication guide without redoing data profiling. Root copies of the original renderer/scripts remain valid compatibility paths.
