# combined review

Inspect the task contract, actual result/diff/artifact, and existing validation evidence. Review purpose and correctness together, reusing the same evidence. Produce one deduplicated issue set ordered by severity, with location, impact, and correction. Explain the chosen tradeoff only when it affects the user decision. No separate purpose-review and correctness-review cycles or second approval are required. Repeat review only after a change, failed evidence, or an unresolved material concern.
