# 从品牌首页到小组件的工艺

用于组件实现与精修。先继承页面的字形、空间、色彩、材质和动作语言，确定组件要表达的信息与操作，再选择适合的交互原理。需要实际示例时通过 [参考源](design-reference-sources.md) 查对应组件；不用把整个组件库带入上下文。

| 组件 | 品牌与交互决定 |
|---|---|
| 导航、菜单、标签 | 导航当前态清楚；开合保持触发点与内容的空间关系；键盘、Escape、返回焦点和触摸操作完整。可借鉴从按钮展开为菜单的连续性，但根据内容选择合适形态。 |
| 按钮与关键行动 | 清晰命名和主次关系；按压马上反馈，悬停与焦点可辨认；加载状态保持尺寸并防止实际重复提交。动效不能推迟执行。 |
| 搜索、输入与表单 | 字号、基线、图标与内边距协调；聚焦、输入、校验、错误和恢复保持稳定；标签不被占位符替代；长文案和输入法使用正常。 |
| 图片展示、比较与轮播 | 裁切围绕主体；切换方向与空间连续；拖拽有边界和释放反馈；比较器与轮播提供触摸、键盘及可发现的替代操作。 |
| 上传、生成与异步结果 | 拖入、可接受、上传中、完成、失败与重试有对应反馈；进度来自真实状态。进度未知就表达等待，完成后确认真实结果；上传框适配点击选择和键盘。 |
| 数据、列表与工作台 | 通过版式、数字对齐、信息分组和状态区分建立品质；数值变化与选中状态可追踪；保留真实数据含义和必要密度。只有任务需要时才做重排或大幅形变。 |
| 提示、空态与错误 | 提示出现位置与触发操作相关，布局稳定且可读；给出明确下一步。空态和加载态使用同一品牌语言，真实业务状态优先。 |

把可复用选择写进现有 token 和共享组件：文字尺度、内容宽度、间距节奏、圆角、线条、深度、焦点、动效时长与缓动。产品文字使用产品自己的语气。浏览器选择高亮、文本光标、滚动条、下划线和数值排版在适合的平台内协调；保留系统可访问性和用户偏好。

强调组件在真实任务中的细腻手感：点击可中断动画，拖动跟手，快速切换不会闪回，禁用与错误可辨，异步结果真实可用。只在合适的品牌与操作中使用磁吸、液态、倾斜、音效或粒子；以用户操作为依据调节强度。已有安静的整体视觉也可以通过精确反馈达到高制作感。

一次核对代表性状态、长内容、桌面指针、触摸和键盘路径；修复导致问题的共享规则或具体组件，再确认受影响路径。涉及帧率、滚动或动态布局时加载 [动效制作](motion-production.md)。
