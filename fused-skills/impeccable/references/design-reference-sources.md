# 设计参考源与选择方法

按需读取：建立新方向、需要整页或区块参考、需要具体微交互时。本轮访问日期为2026-10-05；网站内容、可访问范围和案例可能变化。以下“观察”限于实际公开页面或官方描述，“设计转化”是本技能的判断。开始实际项目时核对需要使用的实时页面；同一项目已记录的参考可以复用。

## 参考入口

| 来源 | 本次可访问内容与观察 | 适合借鉴与转化 |
|---|---|---|
| [FWA](https://thefwa.com/) | [官方获奖动态](https://thefwa.com/rss/)与案例页可以核对作品、获奖日期及原站。 | 整体视觉主张、品牌资产、叙事和交互。先确认真实获奖记录，再打开作品本身；获奖不等于适合当前任务。 |
| [Design Rocket](https://designrocket.io/) | 公开首页可查看。观察到宽幅首屏、大标题、色光背景、较安静的导航，以及学习、平台与模板区块；部分媒体在当前浏览器未播放。 | 首屏层级、产品展示及营销页面节奏。提取适合的空间与主次关系，用目标品牌资产和真实证据重新组织。 |
| [MotionSites](https://motionsites.ai/) | 公开展示整页、Hero、功能、CTA与Footer等分类，也有动态背景入口；部分提示内容需解锁。 | 按当前页面部位选择构图或运动参考。图库中可见不同风格，应先确定一个品牌方向，再统一各区块。 |
| [on.design](https://on.design/) | 本次跳转登录页；公开界面有多种设计作品拼贴、明显主标题和集中的登录操作。内部作品库未访问。 | 保留为设计发现入口；当前只借鉴所见公开构图。未来在有访问权限时检索相关案例，并重新记录实际来源。 |
| [Bencho](https://bencho.dev/) | 公开交互组件库按Hover、Press、Drag、Slide、Swipe、Type、Select分类；查看了Create menu公开详情，有Preview、Code和外观参数。 | 按操作类型查菜单、输入、比较器、上传、列表与反馈。先选对用户任务的互动，再把形态、时序和视觉统一到品牌。 |

来源素材和代码实际使用前核对其授权条件；不把付费入口或登录后的内容视为已经读取。无需为一般灵感观察下载整站资源或安装关联服务。

## 一个实际获奖参照

[Agrumea Farm 的FWA记录](https://thefwa.com/cases/agrumea-farm)确认2026-09-27获FWA of the Day，并提供[品牌原站](https://www.agrumeafarm.it/en)。官方描述介绍了沉浸体验与Three.js、Nuxt、GSAP、Lenis的运用。本次实际打开原站，观察到浅奶油底色、酒红与橙色关系、包装字形和产品罐作为主角的构图。

设计转化：把真实产品包装的视觉语汇放大到页面字形、色彩、构图和动作中，让首屏辨识度来自产品。它提供的是一种资产与品牌统一的做法；项目是否需要3D和滚动编排，要根据自己的内容、设备与任务决定。本次没有测量该站帧率、移动表现或Core Web Vitals，不能把这些能力写成已验证结论。

## 从参考到自己的作品

针对当前品牌选择一个主方向，按需要补充页面部位或组件参考。用精简记录保存：具体URL与日期；实际看过的画面或行为；借鉴部位；为什么符合目标；如何用自己的字体、色彩、素材、文案和操作改写；设备与实现约束。来源不可访问时，说明范围并使用已可访问的参考继续任务。

整页优先研究焦点、叙事和空间；区块研究内容组织与衔接；组件研究反馈、状态和连续性。只看截图可以判断构图，判断运动要看实际操作或录像，判断性能要测量。最后通过统一token、资产风格和动作语言完成融合，并在实际页面中验证。回到 [品牌制作](brand-production.md)、[组件工艺](component-craft.md)或 [动效制作](motion-production.md)继续当前工作。
