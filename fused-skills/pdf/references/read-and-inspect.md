# read and inspect

Use text extraction for content/search and rendered pages for appearance. Inspect only requested/relevant pages, preserving page numbers and source provenance. Use pdfplumber/pypdf for text/metadata, Poppler or PyMuPDF for raster previews. Scanned pages may require OCR; distinguish OCR uncertainty from source text. Do not author a new PDF or run artifact-authoring markers for a read-only request.
