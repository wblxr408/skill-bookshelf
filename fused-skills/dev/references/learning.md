# Evidence-scoped learning

engineering-memory and Basic Memory project main remain the knowledge owner. Reuse its existing event-driven capture and background incremental reconciliation; do not register a second observer or install ECC Memory Vault/Context Keeper as another default database.

Adapt continuous-learning-v2's useful model: one trigger, one actionable behavior, project scope, evidence, confidence/uncertainty, applicability and revision history. Source observations from user correction, a reproduced failure, verified resolution or repeated useful workflow; neither tool count nor repetition alone establishes truth. Store project-specific behavior with its project identity and exclusions. Promote to broader applicability only after evidence in independent contexts or an explicit user preference.

For repeated patterns use workflow-skill-capture: distinguish recallable knowledge from executable guidance, consolidate duplicates semantically, and graduate a stable workflow to a short discoverable skill with supporting references. Preserve contradictory/newer evidence and explicit source provenance. Do not turn accepted preferences into proven technical effectiveness or share externally by default.

Use growth-log/agent-self-evaluation as a compact reflection on evidence gaps and actionable improvements, not a numeric self-pass or automatic rewrite. Rule distillation and skill-stocktake compare real task outcomes and semantic overlap; do not create or run hash, file-size or wording-match checks unless the user explicitly requests the specific check; fixed scores cannot establish acceptance. Use context-bridge at genuine milestones/pressure; no arbitrary 50-call trigger or periodic full scan.
