# agent routing

Retain omo's risk/location/scope signals: known low-risk locations can be handled directly; unclear ownership calls for focused exploration; architectural uncertainty merits design judgment; external dependency behavior merits source research. Choose roles from the actual evidence gap, then give each the original goal, relevant context, constraints, target, and acceptance criteria.

Use native subagents only when authorized. codeagent-wrapper remains available with presets, backend choice, session resume, worktree reuse, parallel tasks, and structured output, using the installed codeagent adapter. The user's existing backend preference wins; otherwise use the current backend. Parallel independent output is optional, not an automatic response to every coding request. Shared-file edits need ownership boundaries and integration review.
