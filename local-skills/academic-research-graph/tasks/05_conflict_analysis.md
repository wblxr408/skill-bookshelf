# Conflict Analysis

## Candidate detection

Look for language such as:

- contrary to
- unlike previous work
- fails to
- cannot reproduce
- overestimates
- underperforms
- invalid assumption
- data leakage
- unfair comparison
- not statistically significant
- sensitive to
- only holds when

Also inspect negative results, replication studies, comments, corrections, and rebuttals.

## Comparability matrix

Before labeling a conflict, compare:

- question
- population/domain
- dataset and split
- metric
- baseline implementation
- compute/model scale
- protocol
- statistical treatment
- version/date

## Adjudication output

For each conflict produce:

- disputed question
- paper A claim and evidence
- paper B claim and evidence
- comparability score
- conflict class
- likely explanation
- later evidence
- current assessment
- confidence

A difference in result is not automatically a contradiction.
